# 沪教版中小学知识图谱与同步辅导（数学 1-12 年级 · 英语 1-12 年级）

用「知识点节点 + 先修边」有向无环图（DAG）描述**沪教版数学（小学一年级上至高中选择性必修第二册，小学 10 册 + 初中 8 册 28 章 + 高中 6 册 22 章）**与**沪教版英语（小学一年级至高中三年级，义教 18 册 + 高中 7 册）**的知识结构，严格对齐课本目录，并在每个知识点上附加**课本同步精讲四件套**与**配套题库**，配合自适应诊断工具实现“学—练—测—补”闭环。数学的小学段、初中段与高中段用同一条先修链连接，诊断可以从高三「导数的应用」一路回溯到小学的「用字母表示数」；英语自成一图（`cne_*`），与数学不连边，覆盖语音、词汇、语法、日常表达、读写五个领域，**按教材 Unit 切分**（每册每个 Unit 一个知识点），**每册另配 1 套册末 mini 卷**（`level: "paper"`），**只出笔试题，不含听力与口语**。数据格式与设计思路源自 [Marble os-taxonomy](https://github.com/withmarbleapp/os-taxonomy)，底座来自 [momoheal/cn-math-taxonomy](https://github.com/momoheal/cn-math-taxonomy) 的 `topics + dependencies + standards + questions + diagnose`。**本仓库地址：<https://github.com/momoheal/studyhard>。**

### 1.4 英语（一至九年级）的教材与课标

- **教材**：上海教育出版社《英语》（沪教版），**一年级起点**；一至五年级为小学、六至九年级为五四学制初中（六年级为预备班），义教段共 18 册、**180 个 Unit**（一、二年级每册 10 个 Unit，三至六年级每册 12 个 Unit，初中每册 6—8 个 Unit）。各册 Unit 目录见 [docs/english-chapters.md](docs/english-chapters.md)。
- **起点更正（重要）**：本项目早期版本把英语写成“三年级起点”，只建了三至九年级的图，属于**错误**。沪教版英语在上海是**一年级起点**（2024 年起一年级启用新版，二年级 2025 年春跟上），本版已补齐一、二年级共 **4 册、40 个 Unit、4 套册末卷、400 道题**，并把全库相关计数、文档与前端文案一并更正。
- **版本说明（重要）**：沪教版《英语》依据**《义务教育英语课程标准（2022 年版）》**修订，于 **2024 年**经国家教材委员会专家委员会审核通过。**不存在“2024 年版英语课标”**，2024 是教材审定年份，数据里用 `source.year = 2022`（课标）与 `source.textbook_year = 2024`（教材）分别标注。详见 [docs/standards-mapping.md](docs/standards-mapping.md)。
- **课程标准**：`data/cn-english-curriculum-standards.json` 共 **55 条**（语音 8、词汇 10、语法 19、语篇 9、语用 9），按学段分三级：一级（3-4 年级）12 条、二级（5-6 年级）19 条、三级（7-9 年级）24 条；id 形如 `ces-2022:3.GR.03`（学段.领域.序号），为本项目自编编号，**全部为归纳表述（`verbatim: false`）、未与教育部 PDF 逐页核对**。
- **知识点粒度**：按**教材 Unit** 切分，一个 Unit 一个知识点（`level: "unit"`），义教段共 **180 个**（语音 1、词汇 67、语法 34、日常表达 48、读写 30），另有 **18 套册末卷**（`level: "paper"`，统一归入「读写」），合计 198 个知识点。`chapter` 形如 `一年级上 Unit 1 Hello!` 或 `一年级上 册末卷 期末模拟`。英语图与数学图**不连边**，英语图的根节点为一上 Unit 1，带 `root_reason` 说明。
- **先修边**：同册「上一 Unit → 本 Unit」为 hard；「上一册末 Unit → 本册首 Unit」为 hard（合计 179 条）；每册每个领域的第一个 Unit 与前面最近的同领域 Unit 之间补一条 soft 边（120 条），用于跨册回溯同类语言知识；每套册末卷只与本册首、末 Unit 各连一条 soft 边（18 条），因此不进入常规单点路径。
- **册末卷（`level: "paper"`）**：每册 1 套 10 题（8 选择 + 2 短答），按该册各 Unit 的核心词与语法点自写，用于整册回看；卷内题目全部挂在该卷知识点上，`chapter` 形如 `一年级上 册末卷 期末模拟`。

- **课标**：`data/cn-highschool-curriculum-standards.json` 共 **54 条**（必修 29：数与代数 16、图形与几何 7、概率与统计 5、综合与实践 1；选择性必修 25：数与代数 7、图形与几何 9、概率与统计 8、综合与实践 1），id 形如 `cmh-2017:1.NA.01`（学段.领域.序号），依据《普通高中数学课程标准（2017 年版 2020 年修订）》【内容要求】，**为归纳表述（`verbatim: false`）、未与教育部 PDF 逐页核对**，`page_or_ref` 一律“待核”；54 条全部被引用。
- **先修衔接**：高中段 106 条先修边全部为 hard，既在高中内部串联（如「导数与函数的单调性 ← 导数的运算 ← 导数的概念」「圆锥曲线 ← 圆的方程」），也跨学段指回初中与小学（如「函数的概念与表示 ← 正比例函数和反比例函数」「集合的概念与表示 ← 用字母表示数」），使数学图成为贯通 1—12 年级的 DAG。
- **建模两册**：必修第四册与选择性必修第三册以数学建模活动为主，本版只在选择性必修第三册设 4 个建模知识点（建模流程、函数模型、统计模型、几何与优化模型），不按活动条目细分，也不与其分册逐页对应；两册的课标综合与实践条目已分别挂到高中建模与探究类知识点上。

### 1.7 习题


- **题型**：英语 Unit 的 4 道基础题（词义选择、拼写、选词填空、翻译）之外，每点再加两组练习——小学：**首字母填空短文（4—5 空，逐空成题）+ 连词成句**；初中：**语篇语法填空（6 空，逐空成题）+ 情景问答**；高中：**语篇语法填空（10 空，逐空成题）+ 中译英 3 句**。每册另有一套 10 题的**册末 mini 卷**。一、二年级每点 9 题，三上至六下每点约 9—10 题，初中每点 11 题，高中每点 17 题，全库共 2436 道英语题。
- **数学题**：小学 628 题（numeric 425、choice 197、short 6）、初中 656 题（numeric 492、choice 164）、高中 344 题（numeric 277、choice 67）；高中题全部带 `verify` 表达式，可独立复算。
- **课本习题**：诊断题与辅导例题的设计严格对齐课本例题与练习的题型与难度，习题文本自行命制，不直接复制课本原题（避免版权问题），但题型、知识点与解题思路与课本一致。
- **外部题库**：题库中数值计算、应用题、几何测量等题目可自行选取市面常见教辅题型改编，确保答案可机器核验。

### topics.json 字段

正式知识点（`external: false`）：

| 字段 | 说明 |
|---|---|
| `id` | 稳定 id：数学 `cnm_001` … `cnm_407`（小学 001–157，初中 158–321，高中 322–407）；英语 `cne_001` … `cne_233`（按册次与 Unit 顺序编号：义教 Unit 001–140 与高中 Unit 141–168，一、二年级 Unit 190–229，册末卷 169–189 与 230–233） |
| `name` | 中文名称（与课本小节名一致或高度概括） |
| `domain` | 数学：数与代数 / 图形与几何 / 统计与概率 / 综合与实践；英语：语音 / 词汇 / 语法 / 日常表达 / 读写 |
| `subject` | 仅英语节点显式写 `"english"`（数学节点省略该字段，缺省视为数学） |
| `grade` | 数学 1–12（1–5 小学、6–9 初中、10–12 高中）；英语 1–9（沪教版一年级起点）与 10–12（高一/高二/高三） |
| `semester` | "上" 或 "下" |
| `chapter` | 课本章节：数学如 `六年级上 第一章 数的整除 1.1 整数和整除的意义`、`必修第一册 第1章 集合与逻辑 1.1 集合初步`；英语按“册 + Unit + Unit 名”书写，如 `一年级上 Unit 1 Hello!`、`必修第一册 Unit 1 Our world` |
| `type` | conceptual / procedural / reasoning / application / modeling |
| `description` | 通俗说明（1-2句） |
| `mastery_criteria` | 2-3 条掌握标准 |
| `diagnostic_question` | `{ "question": "...", "answer": "..." }` |
| `external` | `false` |
| `standards` | 课标映射数组 `[{ id, confidence, note? }]` |
| `tutoring` | **辅导四件套**：`{ key_points(2-3条), worked_example{problem, steps(2-3), answer}, common_mistakes(2条), coaching_tip(1条) }` |
| `level` | 仅英语：`"unit"`（教材 Unit 级） |
| `book` / `unit_no` | 仅英语：所属册次（如 `三年级上`、`选择性必修第一册`）与教材 Unit 序号 |

学前外部节点（`external: true`）：`id: cnm_ext_001` … `cnm_ext_012`，`grade: "学前"`，仅有 `name/domain/description/external/standards`。

### dependencies.json 字段

```json
{"topicId": "A", "prerequisiteId": "B", "strength": "hard", "reason": "一句中文理由"}
```

含义：**A 依赖 B**（学 A 之前需要 B）。hard 会 B 基本无法学 A，soft 会 B 有帮助但非硬门槛。

### 题库（questions.json）

每个正式知识点 **4 题起**（数学：basic 2、standard 1、advanced 1；英语 Unit：基础 4 题 + 扩充的逐空填空与短答，只出笔试题；册末卷：10 题）：

| 字段 | 说明 |
|---|---|
| `id` | `<topicId>_qN`，如 `cnm_052_q1` |
| `topicId` | 知识点 id |
| `difficulty` | basic / standard / advanced |
| `type` | numeric / choice / short（short 用于含单位、时间等非纯数字答案；英语只有 choice 与 short） |
| `prompt` | 中文题干（纯文字，不依赖图形） |
| `answer` | 字符串（numeric 为可解析数字，choice 为选项字母） |
| `choices` | choice 题的 3-4 个选项 `{key, text}` |
| `explanation` | 中文解析 |
| `verify` | 可选，Python 表达式用于机器核验 |
| `accept` | 可选，等价答案列表 |
| `exact` | 可选，仅短答题；为 `true` 时答案唯一，判题器对不上即判错（首字母填空、语篇填空的每个空、词形填空都用它） |

`topics.json` 中原有的 `diagnostic_question` 保留为第 1 题的原型（`_q1` 题干以其开头）。

## 4. 辅导设计（新增）

每个正式知识点在浏览页均可展开**同步辅导卡**：

1. **要点精讲（key_points 3条）**：用家长/学生易懂的语言提炼课本定义、操作步骤与联系生活的应用。
2. **例题精讲（worked_example）**：1 道与课本例题同类的小例题，含 2-3 步解法与答案，家长可照着讲。
3. **常见错误（common_mistakes 2条）**：列出该知识点学生易错点（如进位漏加、单位混淆）。
4. **辅导建议（coaching_tip 1条）**：给家长的具体话术或活动建议（如“先摆小棒再列式，多问一句怎么想的”）。

浏览页 `index.html` 中点击知识点即可查看；诊断工具结果页中每个薄弱根因也提供“查看辅导要点”跳转链接。所有辅导内容由 AI 基于课本生成，**需教师审核**，仅供家庭辅导参考。

## 6. 运行校验与重建

小学辅导内容按册维护在 `_builder/content/g1.py`～`g5.py`，每个知识点一条记录（要点、例题、错因、话术、4 题）；初中内容在 `_builder/jcontent/j6a.py`～`j9b.py`。修改后运行：

```bash
python3 _builder/apply_content.py   # 小学：合并辅导卡与题库到 data/*.json
python3 _builder/build_junior.py    # 初中：重建 158–321 号知识点、先修边、题库与第四学段课标条目
python3 _builder/build_high.py      # 高中数学：重建 cnm_322–407 号知识点、先修边、题库与高中数学课标条目文件
python3 _builder/build_english.py   # 英语：重建 cne_001–233 号知识点（含 25 套册末卷）、先修边、题库与两个英语课标条目文件
python3 scripts/gen_english_doc.py  # 由 data/topics.json 重新生成 docs/english-chapters.md
python3 scripts/gen_highschool_doc.py # 由 data/topics.json 重新生成 docs/highschool-chapters.md
python3 scripts/validate.py
python3 scripts/verify_questions.py
node tests/test_engine.js
```

`validate.py` 检查 JSON 合法、id 唯一、必填字段、取值合法、边存在且无环、非外部点有先修、题库格式与覆盖等；学科相关的取值按 `subject` 分流校验（数学 `cnm_*` + 四个数学领域 + 1–12 年级；英语 `cne_*` + 五个英语领域 + 1–9 年级与高中 10–12 年级），并同时校验五个课标条目文件（数学小学、数学初中、高中数学、义教英语、高中英语）。`verify_questions.py` 对带 `verify` 的 numeric/choice 题做受限表达式求值核验，输出 `data/verification_report.json`。当前 `VALIDATION PASSED` 且 `VERIFICATION PASSED`（mismatch 0）。

## 7. 已知局限

- **审核缺位**：先修图、辅导四件套、题库答案均未经教师审核，不能直接用于教学决策。
- **目录过渡**：小学二至五年级为“试用本”目录，新版发布后需更新；一年级为2024新版已核对但仍建议以课本实物为准。
- **初中教材版本**：初中章节按现行通行目录（第一至二十八章）编写；上海 2024 年审定版新教材正在六、七年级推开，章次编号与顺序有调整，未逐册核对，使用前必须以课本为准。
- **初中先修边**：初中 169 条先修边全部标为 hard（尚未做 soft 强度分级），且跨学段边只覆盖 20 余处，粒度与强度都需教师重审。
- **题库规模**：每点 4 题、诊断每点最多 2 题，选择题有猜对概率，结果仅为线索；初中题以数值计算与单一事实判断为主，证明题、作图题未覆盖。
- **图形题**：题干纯文字，无配图；作图与证明题未覆盖。
- **辅导深度**：每个知识点的要点、例题、错因、话术均按该知识点单独编写，但篇幅较短，未针对上海教研细节（如“沪教版巧算策略”）逐条打磨，需一线教师补充。
- **英语范围**：覆盖沪教版义教 18 册（180 个 Unit + 18 套册末卷）与高中 7 册（28 个 Unit + 7 套册末卷），共 233 个知识点；一、二年级 40 个 Unit 的单元名按新版教材目录整理，**未逐册与课本实物核对**；只出笔试题，**不含听力与口语**；各册 Unit 名按公开电子课本与教辅目录整理，**未逐册与课本实物核对**；课标条目为归纳表述，未与 PDF 逐页核对。关于“2024 版课标”的澄清见 1.4 节。
- **英语题目形态**：义教段的基础 4 题由「单元核心词 + 重点句 + 译文」自动生成（词汇选择题、拼写题、选词填空、翻译），在此基础上每点追加两组手写练习：小学是首字母填空短文（4—5 空，逐空成题）与连词成句，初中是语篇语法填空（6 空，逐空成题）与情景问答；高中是语篇语法填空（10 空，逐空成题）与中译英 3 句。全部文本为自写，未引用现成教辅原题；同一短文的多个空各自成题，题干都会带全篇，因此题量增长快于篇数。册末卷 10 题覆盖整册，但仍属 **mini 卷**，**不能替代单元测验或期末考试**。
- **英语先修强度**：同册 Unit 链全部标 hard（教材本身按序编排），跨册同领域边标 soft；「某 Unit 一定需要上一 Unit」这一判断仍需教研审核。
- **高中数学**：86 个知识点按沪教版 2020 年审定教材的册/章/节拆分，**未逐页核对课本与教师用书**；章节目录、小节编号（尤其必修第三册第 10—11 章、选择性必修第一册第 1—4 章）以公开目录与教辅整理为主，教师使用前请以课本为准；两册数学建模（必修第四册、选择性必修第三册）只做了 4 个建模知识点；高中数学题以计算与判断为主，**证明题、作图题、动态几何未覆盖**，先修边全部标 hard（未做 soft 分级）。
- **英语判题**：短答题按规范化文本匹配并配 `accept` 列表；标了 `exact: true` 的填空题（951 道）对不上即判错，其余翻译、情景问答、连词成句只能宽松匹配并回落到“对照参考答案自评”，**不能代替教师批改**；题目难度为 AI 主观标注。
- **多空短文**：同一篇短文的 5/6/10 个空各自成题，题干重复整篇短文，是为了让每个空都能被精确判分；若更看重“整篇一次做完”的体验，可后续在页面上做组题视图。
