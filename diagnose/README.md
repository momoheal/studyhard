# 知识点诊断小工具（沪教版数学 1-9 年级 · 英语 3-9 年级）

纯静态、可离线的网页小工具：选目标知识点或整章，沿先修关系自适应出题，找出**薄弱根因**与**不稳点**，给出**按拓扑序的学习路径**、**课标依据**与**辅导要点**，支持导出与打印。无构建、无 CDN、无后端；进度仅存浏览器 localStorage。

开始页可切换**数学 / 英语**：数学覆盖沪教版 1-9 年级（`cnm_*`），英语覆盖沪教版 3-9 年级（`cne_*`，依据 2022 年版课标、2024 年审定教材，只出笔试题）。两科单独成图，先修关系互不相连。

> 数据（知识点、先修边、课标、辅导四件套、题库）均为 AI 草稿，未经教师审核，结论仅供家庭辅导参考。

## 运行

在项目根目录（非 `diagnose/` 内）：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/diagnose/
```

页面通过 `fetch('../data/*.json')` 读取数据（含题库与辅导卡），不能用 `file://` 直接打开。

### URL 参数

| 参数 | 含义 |
|---|---|
| `target=cnm_052` | 直接以某知识点为目标（逗号分隔多个）；`target=cne_021` 会自动切到英语 |
| `chapter=一年级上 第三单元` | 以整章为目标（写法同浏览页分组标题，需 URL 编码）；英语用 `chapter=三年级上 全册 语音` |
| `demo=1` | 演示：模拟学生作答并直接到结果页，不读写存档；目标两题错→薄弱，其先修一错→薄弱根因，其余一错一对→不稳 |
| `step=2` | 与 `demo=1` 合用：仅自动答前 2 题，停在第 3 题出题页 |
| `limit=16` | 题量上限（按题计，默认 16，可调 8-30） |
| `seed=abc` | 固定随机种子，同目标同作答出题完全一致 |

例：`http://localhost:8000/diagnose/?target=cnm_052&demo=1`

## 使用流程

1. **开始页**：按年级/册/章节浏览，或搜索知识点；可设题量上限（8-30）。
2. **出题页**：每题显示知识点、难度、题型、第几题及出题原因（目标本身 / 回溯先修 / 复测）。数值题输入答案，选择题点选项；提交后即时显示参考答案与解析，并可“判错了”手动更正。支持“不会”、撤销上一题、重新开始。
3. **结果页**：薄弱根因（及挂起的先修）、不稳点、学习路径（拓扑序，基础在前目标在后，含辅导卡链接）、路径图（SVG）、已掌握/未测列表、课标汇总、答题记录（可逐题更正，重算结果）。可导出 JSON、打印/PDF；进度自动保存，支持继续/放弃存档；已出题 id 记录避免重复（可清除）。

## 算法（engine.js）

- **图**：`topicId → prerequisiteId` 为先修；先修子图 = 目标 + 所有祖先（拓扑序，先修在前，同层按 topics 文件顺序，hard 优先）。
- **出题栈**：初始为目标按“离目标最近”排序，先问目标本身。每点最多 2 题：
  - 第一题对 → 掌握，并推断其所有祖先为“掌握（推断）”；
  - 第一题错 → 再出第二题（同级或更易，优先 basic）：
    - 第二题对 → 不稳（shaky，不回溯）；
    - 第二题错/不会 → 薄弱（weak），将其可测先修（hard 先）压栈顶深度优先回溯；
  - 小学外部节点无诊断题，不出题，未推断则标“未测”。
- **选题**：伪随机（mulberry32，种子为 `(seed, 知识点, 第几题)`），同作答下完全可复现；优先未出过的题（`localStorage` 记录 `avoid`），第一题避开 advanced，第二题按难度分层。
- **判题**：`judgeQuestion(question, userText)` 按题型（choice 比字母/文字、numeric 数值等价、short 精确匹配、self 自评）与数值规范化（全角转半角、单位别名等）判定；不可靠时返回 `manual` 让用户对照自评。
- **结果**：根因 = 薄弱且先修无薄弱；路径 = 根因与不稳出发沿依赖可达、去除已掌握的拓扑序；含 pending/外部先修提示与未复测标记。`replay` 可由记录重建会话，保证刷新/撤销/更正的一致性。

## 辅导联动

- 结果页每个根因与不稳点均附“查看辅导卡”链接，跳转至浏览页 `index.html#<id>` 的同步精讲四件套（要点、例题、错因、家长话术）。
- 出题页解析区也引用辅导卡中的“常见错误”作为提示（若该知识点有辅导数据）。

## 局限

- 每点最多 2 题，题库每点仅 4 题，重测会重复，线索非结论。
- 不稳不回溯可能漏掉先修薄弱，已在路径中标出建议自查。
- 答对即推断祖先掌握，依赖先修图准确性（AI 生成未审核）。
- 学前外部节点标“未测”，无法细定位到学前根因。
- 判题仅覆盖数值、选择与简单短答，代数式与文字题需自评。
